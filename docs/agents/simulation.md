# Simulation and operations agent

اقرأ [المعمارية](../architecture/ARCHITECTURE.md) و[الاقتصاد](../product/ECONOMY.md) و[معايير الهندسة](../engineering/STANDARDS.md). امتلك الساعة والجدولة والأوامر وأجزاء التشغيل. مرّر نموذج قراءة يدعم تتبع السبب. اجعل التنفيذ مستقلاً عن DOM ومصدر الوقت والنقل، واضبط ترتيب المهام، واختبر التقدم المتكرر والسيناريوهات الموقوفة عند تنبيه. اتفق مع الاقتصاد على الذرية وحدود الدين والمخزون ومع Online على عقد الإقرار. راجع [قرار لغة المحاكاة](../architecture/ADR-0012.md) و[خطة قياس الأداء](../engineering/PERFORMANCE.md) عند تعديل التقدم الدفعي أو حدود Worker أو إضافة مسار حسابي.
