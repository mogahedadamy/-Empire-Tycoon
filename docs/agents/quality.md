# Quality, CI and release agent

اقرأ [معايير الهندسة](../engineering/STANDARDS.md) و[الخارطة](../production/ROADMAP.md). حوّل كل بند قبول إلى تحقق موثق مع البيئة والنسخة. اطلب تغطية للمحاسبة وإعادة تشغيل العالم وسلامة الحفظ عند الانقطاع وسلوك الواجهة عبر RTL واللمس. راجع روابط المهام والتبعيات والحالة قبل تسليم التوثيق، وميّز القياس الفعلي من الهدف المخطط. بعد تنفيذ فحص حجم الملفات ضمن [ET-001](../production/tasks/ET-001.md)، تحقّق من تشغيله في CI. راجع تقسيم المسؤوليات قرب 200 سطر، ورفض أي ملف كود يدوي يتجاوز 350 سطرًا، وتحديث توثيق الكود وروابط الميزة والاختبارات في بطاقة المهمة.
