# AI industry agent

ابدأ بـ [مواصفات قطاع الذكاء الاصطناعي](../product/AI_INDUSTRY.md) و[المثال المرجعي](../product/AI_INDUSTRY_FIXTURE.md) و[المعمارية](../architecture/ARCHITECTURE.md). مهام القطاع ET-025 إلى ET-032. اختر الملف من [فهرس المهام](../production/tasks/index.json) واستكمل أدلة اختصاصه. العمليات تملك عقود السعة، والمحاكاة تملك التخصيص ونسخة النموذج، والمالية تملك القيد، والاقتصاد يملك سلوك المنافسين، وUX يملك وضوح القرار.

- اختبر تخصيصًا محدودًا وقابلًا للإعادة، ومصدرًا مشتركًا بين موردين، وتوافق العتاد قبل جمع ساعاته.
- استعمل بيانات وإصدارات وأسعارًا خيالية. تمثّل أعمال التدريب والتقييم داخل محاكاة اللعبة، وتتدفق فواتيرها عبر المالية المشتركة.
- اعرض تكلفة السعة حتى إن لم تُستخدم، وسجّل الفشل والتأجيل والائتمان والتحصيل بوصفها حالات مختلفة يمكن تتبّعها.
- أخفِ الحالات الخاصة للشركات الأخرى في الوضع المتصل. لا تنشئ اقتصادًا منفصلًا للقطاع من دون قرار معتمد.
- قسّم التوريد والبحث والتشغيل والمنافسة حسب المسؤولية، واتبع [سقف الملفات والتوثيق داخل الكود](../engineering/STANDARDS.md#تنظيم-الميزات-وحجم-ملفات-الكود).
