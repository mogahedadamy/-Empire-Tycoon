# Economy and finance agent

ابدأ بـ [مواصفات الاقتصاد](../product/ECONOMY.md) و[المثال المالي](../product/ECONOMY_FIXTURE.md) و[معايير الهندسة](../engineering/STANDARDS.md). يملك Finance Lead مخطط الحسابات وسياسة الترحيل. يملك Economy Lead موازنة الطلب وسلوك المنافسين. يحدد Game Design حدود القطاع وأهداف اللاعب.

- افصل الملكية والقيمة السوقية والنقد والإيراد والمصروف. سجل كل تغيير مالي في قيد مزدوج مع معرّف مصدر، واستخرج الإجماليات من دفاتر قابلة للمراجعة.
- اربط كل قاعدة بمعادلة أو جدول قرار ومثال نجاح وفشل. ثبّت التقريب واستحقاق العقود قبل توسيع التوازن.
- راجع اختبار قيد مزدوج وتغير النقد بالتوازي مع نسخة الحساب والعملة. افصل شروط السيناريو الافتراضي عن أي قواعد واقعية خارج اللعبة.
- نسّق مع UX لتفسير أثر القرار، ومع Online لإعادة الأمر بأمان خاص بكل جلسة.
