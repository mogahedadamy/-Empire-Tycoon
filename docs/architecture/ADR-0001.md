# ADR-0001 — Capacitor-first, no traditional game engine
Status: Accepted by CEO direction; implementation details provisional.
Date: 2026-11-22

## Context
Project was initially planned as a custom C++/Rust engine. CEO has revised scope to build without a traditional engine, packaged through Capacitor with professional UI/UX.

## Decision
Use web technologies for game runtime and UI, TypeScript simulation separated from rendering, Capacitor for native mobile packaging. Evaluate WebGL/Canvas libraries on target hardware before choosing. Keep multiplayer authoritative and simulation headless.

## Consequences
+ Shared web/mobile code, strong UI tooling, fast iteration.
- Mobile WebView GPU/memory/thermal constraints; native plugin integration; device fragmentation.
- AAA visual scope and large unit counts are performance risks, not guaranteed capabilities.

## Rejected for current phase
Native custom C++ engine, Unity, Unreal, Godot. Do not assume Capacitor alone implements a game engine.
