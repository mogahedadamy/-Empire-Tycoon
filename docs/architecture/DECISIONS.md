# سجل القرارات

المقترحات أدناه هي أساس التخطيط. تصبح قرارات التنفيذ قابلة للمراجعة عند التكليف به. كل قرار أُرجئ له مالك ومهمة إغلاق.

| المعرف | الحالة | القرار أو سؤال الحسم | المالك / نقطة الحسم |
|---|---|---|---|
| ADR-0001 | معتمد بتوجيه صاحب المشروع | تقنيات الويب + Capacitor؛ يستمر هذا الأساس. تفاصيل الرسم في مستند القرار الأصلي تاريخية | CTO |
| ADR-0002 | اتجاه معتمد من التكليف؛ التفاصيل مقترحة | استراتيجية أعمال واقعية استنادًا إلى تحليل Business Empire؛ نموذج المقاطعات سابق على الاتجاه الجديد. بدأ تنفيذ الأساس عبر ET-001 | CEO، Game Director |
| ADR-0003 | خط أساس مقترح | محاكاة أيام حتمية مع أوامر وإعادة تشغيل، ومحاسبة مزدوجة منفصلة عن الواجهة | CTO + اقتصاد · ET-002 وET-003 |
| ADR-0004 | خط أساس مقترح | شريحة مدينة واحدة بقطاع غذائي وعملة واحدة؛ تقدم فردي عند الطلب | Game Director · ET-001 وET-004 |
| ADR-0005 | منفّذ للويب | حفظ IndexedDB بمعاملة ذرية ومراجعة تمنع كتابة تبويب متأخر. يُحسم محول الهاتف بعد التحقق على الأجهزة | Platform · [ET-012](../production/tasks/ET-012.md) وET-014 |
| ADR-0006 | منفّذ في معاينة المرحلة A | DOM/CSS ومكونات المتصفح الأصلية للشاشات الثلاث. يُراجع اختيار الإطار عند توسع حالات الواجهة | CTO + UX Lead · [ET-005](../production/tasks/ET-005.md) |
| ADR-0007 | خط أساس مقترح | موسم متصل مستقل بخادم مرجعي؛ صيغة التنافس والميزانية والتشغيل تُقاس قبل الالتزام | Online + Game Director · ET-019 وET-020 |

| ADR-0010 | اتجاه ميزة بتوجيه صاحب المشروع؛ تفاصيل موازنة مقترحة | بلد تأسيس حقيقي ضمن البيانات المتاحة وقواعد لعب مؤرخة للتجارة والتمويل والصعوبة والمنافسة. تفصل بوابات الأهلية عن أثر الثقة والضغط التلقائي | Economy Lead · ET-033 إلى ET-036 |
| ADR-0011 | اتجاه ميزة بتوجيه صاحب المشروع؛ نطاق أولي مقترح | إدارة تفويضية للأندية. تبدأ كرة القدم 2026/27 بهويات حقيقية وتغطية معلنة وترتيب وقوة منفصلين | Sports Design + Sports Data · ET-037 إلى ET-042 |
