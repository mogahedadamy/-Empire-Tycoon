## نطاق التسليم

المسارات المقصودة هي package.json وملف قفل التبعيات و.github/workflows/ وtools/ وapps/game/ وملفات النموذج السابق التي تحتاج تنسيقًا أو فصلًا للالتزام بالمعايير. تحدد بنية المستودع الفعلية المسار داخل تلك الحدود.

ثبّت تثبيت الحزم وفحصها، سجّل وضع النموذج السابق، وأنشئ حد دخول واضحًا للعبة الجديدة وخريطة بناء للحزم. أضف فحص حجم الملفات ووثّق طريقة تشغيله محليًا. نسّق ملفات النموذج المضغوطة وقسّمها حسب المسؤولية إذا تخطت السقف بعد التنسيق، مع اختبار سلوكها.

## معايير القبول

- أثبت أن تثبيتًا جديدًا وبناءً واختبارات النموذج يعملون
- بيّن سبب أي فشل حالي قبل إيقاف النموذج
- أنشئ نقطة دخول للعبة الجديدة قابلة للتشغيل من README وحدًا يمنع تسرب اعتماد DOM إلى المجال.
- وفّر أمرًا محليًا مثل npm run check:file-size، وشغّله في CI لطلبات الدمج. يغطي الفحص كل ملفات الكود اليدوي في المستودع وفق معايير الهندسة، ويطبع المسار وعدد الأسطر ويعيد حالة فشل عند وجود مخالفة.
- أثبت بأمثلة قابلة للتكرار قبول 200 و350 سطرًا ورفض 351 سطرًا، مع عدّ الأسطر الفارغة والتعليقات والسطر الأخير غير المنتهي بمحرف سطر جديد. تحقق من تطبيق الاستثناءات الموثقة على البيانات ومخرجات التوليد مع بقاء الأكواد اليدوية مشمولة.
- وثّق داخل الكود غرض الوحدات الجديدة وعقودها المؤثرة، وسجّل نقطة الدخول ومسارات القواعد والاختبارات في بطاقة المهمة.

## دليل الإنجاز

تحقّق محليًا على Linux باستخدام Node.js 22.23.5 وnpm 11.19.1 وTypeScript 5.9.3 وVite 6.4.6 وVitest 3.2.7.

| التحقق | النتيجة الفعلية |
|---|---|
| خط أساس النموذج قبل التعديل، `npm install` و`npm run typecheck` و`npm test` و`npm run build` | نجحت الأوامر على [النسخة المرجعية](https://github.com/mogahedadamy/-Empire-Tycoon/commit/8e2e84756002185682b3f580e38e1a01466f2b68)، بما فيها اختبارا النموذج. |
| تثبيت من [ملف القفل](../../../package-lock.json) باستخدام `npm ci` | نجح من تثبيت نظيف وثبّت 143 حزمة. |
| `npm run typecheck` و`npm run build` | نجح فحص المشروع والمجال، ونتج `dist/index.html` للنموذج و`apps/game/dist/index.html` للعبة. |
| `npm run check:file-size` و`npm test` | اجتاز الفحص 18 ملفًا يدويًا، ونجحت الاختبارات الثمانية. شملت قبول 200 و350 ورفض 351 مع التعليقات والأسطر الفارغة والسطر غير المنتهي، واستثناء البيانات والمخرجات مع فحص القوالب والمولّدات وسير العمل. أثبت اختبارا حدود المجال رفض `document` ورفض استيراد ملفات مصدر التطبيق. |
| تشغيل المدخلين في Chromium 156.0.8078.79 | ظهرت 96 قطعة أرض. خفّض بناء المزرعة الذهب من 200 إلى 170 والخشب من 100 إلى 85، ورُفض تكرار البناء في نفس القطعة، ثم رفع الموسم التالي الذهب إلى 171. ظهرت رسالة الجاهزية في المدخل العربي واتجاه الصفحة RTL. |
| طلبات الدمج | يعرّف [سير عمل CI](../../../.github/workflows/ci.yml) تشغيل `npm ci` وفحص الحجم والأنواع والاختبارات والبناء. اجتازت الأوامر محليًا، وتشغيل GitHub Actions يتاح بعد رفع التغيير. |

ظهر خطأ `EPERM` في خطوة التحقق من ملف esbuild التنفيذي عند تشغيل `npm ci` تحت قيود بيئة العمل الافتراضية. نجح التثبيت والفحص الكامل عند إعادة التشغيل بصلاحيات الشبكة المتاحة للبيئة، مع ملف القفل نفسه.
