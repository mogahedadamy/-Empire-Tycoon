## نطاق التسليم

المسارات المقصودة هي capacitor.config.ts وapps/game/ وdocs/engineering/. تحدد بنية المستودع الفعلية المسار داخل تلك الحدود.

ثبت دورة بناء الهاتف وإدارة الخلفية ومناطق الأمان. أولوية الإصدار الحالي هي Android أولًا بتوجيه مالك المشروع. يُستأنف بناء iOS والتحقق منه بعد اعتماد شريحة Android. سمِّ أجهزة الاختبار وحدد عينة القياس والأحمال.

## معايير القبول

- سجّل تشغيلًا على جهاز Android مع إصدارات النظام وWebView، وقياس الإقرار المرئي والفتح. يُسجّل التحقق على iPhone عند استئناف مسار iOS.
- أثبت الاستعادة بعد توقف
- سجل تحقق الأجهزة غير المتاحة بوصفه غير منجزًا.
- قس P95 للإقرار المرئي والفتح، وسمّ ميزانية زمن دفعة المحاكاة والذاكرة وحجم العينة. سجّل خط أساس TypeScript عند القياس عبر WebView.

## حدود المهمة

لا إعلان دعم إنتاجي لجهاز لم يُختبر.

## دليل الإنجاز

### التجهيز والفحوص

- يحزم [إعداد Capacitor](../../../capacitor.config.ts) لعبة الأعمال وWeb Worker من `apps/game/dist`. نجح `npm run prepare:mobile -- android` و`npm run prepare:mobile -- ios` بإعداد SPM. طابقت ملفات الإنتاج الـ15 الحزم المنسوخة إلى المشروعين، وسُجّل `@capacitor/app` فيهما.
- نجح `assembleDebug` على Linux باستخدام Gradle 8.11.1 وJDK 21.0.13 وAndroid SDK 35. تحقق `aapt` و`apksigner` من الحزمة `com.empiretycoon.game` الموقعة للتصحيح واستهداف API 35. يحمل `android/app/build/outputs/apk/debug/app-debug.apk` نفس ملفات الإنتاج الـ15 بالضبط، وبصمته SHA-256 هي `ed6005c9890c8fb587e18f992add11ab8134dddcdd7175f3628dd0ae63098737`.
- يجمع [محوّل دورة الحياة](../../../apps/game/src/platform/lifecycle.ts) حالة التطبيق وإشارات الصفحة لحفظ آخر نتيجة مؤكدة عند الخروج وإعادة محاولة الحفظ عند العودة، مع بقاء يوم المحاكاة ثابتًا. يضبط [تنسيق الواجهة](../../../apps/game/src/layout.css) الهوامش الفيزيائية، واختبر Chromium الاتجاهين مع قيم مناطق أمان اصطناعية بلا تمرير أفقي.
- نجح `npm run check:file-size` على 158 ملفًا، و`npm run typecheck`، و`npm test` (87 اختبارًا في 26 ملفًا، منها [3 اختبارات لدورة الحياة](../../../tests/platform/lifecycle.test.ts))، و`npm run build`، و`git diff --check` على Node.js 22.23.5.

### خط أساس TypeScript في المتصفح

أُخذت 20 عينة لكل مقياس على Chromium 156.0.8078.79 في Linux x86_64، في بناء الإنتاج وعرض 390×844. أعادت دفعة المحاكاة نفس حفظ اليوم 19 في كل تكرار، وتقدمت 12 يومًا إلى اليوم 31 عبر الإقفال الشهري. أعاد قياس الفتح تحميل حفظ اليوم 31 مع ذاكرة مؤقتة مفعلة للفتح الدافئ وصفحة جديدة مع تعطيل ذاكرة HTTP المؤقتة لكل فتح بارد. تطابق الحفظ بعد تجميد الجلسة واستئنافها، وبعد إغلاق عملية المتصفح وتشغيلها مجددًا.

| المقياس | الوسيط (مللي ثانية) | P95 (مللي ثانية) |
|---|---:|---:|
| الفتح البارد | 165.2 | 225.0 |
| الفتح الدافئ | 110.2 | 116.2 |
| إقرار العامل | 13.9 | 16.0 |
| الإقرار المرئي | 45.2 | 46.9 |
| نتيجة دفعة 12 يومًا | 31.8 | 33.7 |

سجّل DevTools بعد الدفعة 23.1 MiB من ذاكرة JavaScript المستخدمة في سياق الصفحة، وبلغ حجم لقطة الحفظ 14,937 بايت. ما زالت ذروة ذاكرة العامل والمضيف مجتمعين ودفعة 30 يومًا بحاجة إلى قياس. تشمل [مصفوفة الهاتف](../../engineering/MOBILE.md) العينة والميزانيات وخطوات إعادة القياس.

### التحقق المتبقي

- لم يتوفر جهاز Android في بيئة التنفيذ. تبقى قياسات P95 داخل Android WebView والاستعادة بعد إيقاف عملية التطبيق واختبار حواف الجهاز ضمن بوابة Android.
- تم تجهيز ومزامنة مشروع iOS. أُجّل البناء عبر Xcode والقياس داخل WKWebView إلى ما بعد اعتماد شريحة Android. بدأت [مراجعة ET-015](ET-015.md) بالفحوص المتاحة، ويظل اعتمادها مرتبطًا بتحقق Android الفعلي.
